## 雷达数据源重构（核心工作）
### 背景
无尽模式下第二波 CBT 的 FDC 目标不在 `FireMissionRoot.children` 中，导致雷达无法发现新 spawn 的 FDC。

### 探索过程
1. **Il2Cpp Dictionary 深探**：确认 `FireMission.Entities` = `Dictionary<string, MapEntity>`（40 条，全量目标注册表），`RunningTimers` = `Dictionary<string, TimerValue>`
2. **MapEntity 属性确认**：`ID, Name, Icon, Role, Position, State, MaxHealth, Armour, Stars, Scale, ImmuneShells, Location, Health, IsAlive` — 与 Entity 结构完全一致
3. **坐标系统问题**：`MapEntity.Position` 是游戏公里网格坐标，不在 Draggable Surface 本地空间。`TransformPoint` 直接使用时坐标错误（打到 off-map）
4. **解决方案**：`FireMission.coordinateRoot`（RectTransform, 20×10, pivot=0,0, parent='MapRoot'）是网格坐标→世界坐标的桥梁。`coordinateRoot.TransformPoint(MapEntity.Position)` 给出正确的世界坐标

### 最终架构
- **数据源**：`FireMission.Entities` Dictionary → 枚举全部 40 条 MapEntity
- **存活过滤**：`IsAlive == true`
- **坐标**：优先 `MapEntity.Location.transform.position`（已 spawn），fallback `coordinateRoot.TransformPoint(MapEntity.Position)`（未 spawn 但位置已设定）
- **去重**：从 `ChildIndex`（脆弱的 int 索引）改为 `EntityId`（MapEntity key 字符串）
- **装甲判断**：直接使用 `MapEntity.Armour > 0`，不再仅靠 Role/Icon 推测
