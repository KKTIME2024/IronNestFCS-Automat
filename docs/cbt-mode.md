## 1. 游戏规则（锁定）

| 规则 | 数值/语义 |
|---|---|
| CBT 倒计时 | 开局 600s；**第一发炮弹落地时启动**（敌人开始观测）；**无上限**（**实测**：加时后到 656.6，超 600 不截断） |
| 倒计时推进 | **实测** timeScale=4：游戏 600s ≈ 真实 150s；计时器速率跟随 timeScale |
| 倒计时归零 | **实测**：归零后 remain 钉在 0，再经 ~72 游戏秒 PERMANENTLY-STOPPED → 回合结束（= 反击到达的死亡窗口，非瞬间死） |

| 击杀火炮 | **实测（14 样本）**：CBT **+30s**、征用点 **+5**，两账同步入账（同 0.1s 内），按门计 |
| 击杀伴随目标 | 本局无"火炮+步兵"双杀入账样本；全部入账事件 1:1 对应火炮任务，**步兵是否计分未排除** |

| 目标刷新 | 火炮**无限重生**；FDC 固定 3 个 |
| 初始资本 | 挑战模式约 100 点 |
| **FDC 分布** | **FDC 仅存在于无尽反炮兵模式**——剧情反炮兵关无 FDC、轻松模式无 FDC（用户确认）。FDC 存在 = 无尽反炮兵模式指纹 |

## 2. 经济核算

### 2.1 单发收支总表

装药成本：最低 0.25 点/包 × 距离所需包数（每 5km 一包）；满装 1.5 点/发。

| 弹种 | 成本 | 适用 | 收入 | 净收益 |
|---|---|---|---|---|
| DRIL | 3+药 | 单点软目标 | 火炮 +5 | **+0.5~1.75** |
| DRIL | 3+药 | 单点星标软 | +10/星 | 1★+7、2★+17、3★+27 |
| LE | 10+药 | DRIL 不可用时单点软 | 火炮 +5 | **−6.5~−5** |
| HE | 10+药 | 软集群 | ×N 门火炮 | 2门≈−1、**3门≈+3.5** |
| HCHE | 18+药 | 大软集群 | ×N 门火炮 | 4门≈+0.5~2 |
| AP | 10+药 | 装甲/地下 | 星标 +10/星 | 3★工事≈+20 |
| AP | 10+药 | 高价值/弹药库 | **有收入，数值未统计** | 待实测（可能为正） |

**结论**：
- DRIL 打软目标是唯一无条件正收益的单点弹。
- 星标目标是最大印钞机：3★ 软目标一发 DRIL 净赚 ~+27；3★ 装甲一发 AP 净赚 ~+20。
- HE 集群打火炮 3 门以上才净赚；2 门打平（略亏装药钱）。
- 高价值目标（弹药库等）有征用点收入但数值未统计——实战中观察账本变化后回填，再决定其优先级档位。

### 2.2 装药—仰角—周期三角（核心机制）

**仰角公式（代码锁定）**：`elev = 0.012 × 距离(m) ÷ 装药`；最低装药 `ceil(dist×0.2)` 恰好把仰角顶到 ≈60°（最大仰角）。

| 距离 | 最低装药 | 仰角 | 满装 6 包仰角 |
|---|---|---|---|
| 5km | 1包 | 60° | 10° |
| 10km | 2包 | 60° | 20° |
| 15km | 3包 | 60° | 30° |
| 20km | 4包 | 60° | 40° |
| 25km | 5包 | 60° | 50° |

**连续发射时 ToF 不在关键路径**（炮弹飞行与下一轮装填重叠）——真正受装药影响的是**仰角行程**（升 + 回位降）。但行程差距的幅度取决于高低机速度，当前两说：旧 DEVLOG 实测 1.875°/s（0→60=32s），FSC 代码注释称 4°/s（0→60=15s）——**待进游戏重测**。

**单炮周期**（用户实测最低装药 ≈120s 基准）：

| 高低机速度假设 | 满装节省/发 | 满装击杀间隔(双管) | 每杀净时间 |
|---|---|---|---|
| 4°/s（保守） | 5~20s | 50~57s | −20~−27s |
| 1.875°/s（乐观） | 21~53s | 33~49s | **−3~−19s** |
| 最低装药（基准） | 0 | ~60s | −30s |

→ 满装确实快，但幅度在两说之间差 2~3 倍。**若实测节省 <15s/发，双轨装药收益有限，一律最低装药更简单。**

**积分账（参数化）**：每杀净 = I − 3 − 0.25×包数（I = 火炮击杀收入，DRIL=3 点，装药 0.25/包）。

| 装药 | 每杀净 |
|---|---|
| 最低(1~5包) | I − 3.25 ~ I − 4.25 |
| 满装(6包) | I − 4.5 |

- 装药成本按"每 5km 一包"随距离走（1~5 包），**不是每发固定 5 包**。此前按"5 点 20 包 ÷ 4 发 = 1.25 点/发"算，是把最远目标的约束错套到所有目标上，导致误判满装为负。
- 按 I = 5（用户估计，待实测）：最低 **+0.75~1.75**，满装 **+0.5**——**所有装药档都是正收益**。

**结论（双轨的本质）**：两种装药都正积分，区别在**利润率 vs 节奏**：

| | 最低装药 | 满装 |
|---|---|---|
| 每杀利润 | +0.75~1.75 | +0.5 |
| 击杀间隔 | ~60s | 33~57s（取决于高低机速度，见上表） |
| 定位 | 高利润慢节奏 | 薄利快节奏 |

- 满装提速换算（乐观 1.875°/s）：多花 1 点装药 → 击杀间隔 −10~26s。对比紧急移动 1 点 ≈ 4.3s（按 08-18 样本 ~278s 冻结/65 点折算）——**装药提速的效率远高于紧急移动**，且不亏本（仅摊薄利润）。保守 4°/s 时 −2.5~10s，与紧急移动相当或更优。
- 正确姿势：**时钟宽裕 → 最低装药攒钱；时钟吃紧 → 满装抢击杀节奏；杀不动时（无射程内火炮/断弹药）→ 紧急移动买免费装填期兜底。**（移动不再回 600，只是冻结、我方落地解冻，见 §2.4；满装收益若实测 <15s/发则取消双轨，一律最低装药）

**生存期模型**（T = 击杀间隔；倒计时无上限，600s 只是初始值）：

```
时钟归零: C₀ + 30×N − T×N = 0 → N = C₀ / (T − 30)
最低装药: T=60  → N = C₀/30 杀（C₀=600 → 20 杀 ≈ 20 分钟）
满装@5km: T=33  → N = C₀/3  杀（C₀=600 → 200 杀 ≈ 1.8 小时，利润 +0.5/杀 同时攒 100 点）
满装@20km:T=49  → N = C₀/19 杀（C₀=600 → 31 杀 ≈ 25 分钟）
```

- 无上限意味着：+30s 永远全额入账不溢出；但纯火炮循环每杀净时间仍为负（最优 −3s），**倒计时只会单向衰减，靠 FDC 暂停和紧急移动暂停窗拉回**（两者都只是冻结，不会把值抬回去）。
- **紧急移动不是地板重置（2026-08-18 实测推翻旧模型）**：它冻结时钟，**我方落地后按原值恢复**（暂停无时限，不开炮就挂着；实测一次 ~278 游戏秒自然解冻），不抬到 600。按样本折算 65 点 → 1 点 ≈ 4.3s。它救不回"已经烧掉的低值"，只能**买一段免费装填期**——所以触发点不需要卡在最底，"杀不动 + 有 65 点"就该用。

- 满装在近距离能把失血压到近乎打平；距离越远收益越小（20km 只省 21s 周期）。
- **最优打法是混合轨**：宽裕期最低装药攒存款，吃紧期满装（优先打近距离目标，提速收益最大），杀不动时紧急移动买暂停窗。比"全最低装药"生存期长 2~5 倍。

### 2.3 星标目标经济

| 目标 | 弹 | 成本 | 收入 | 净 |
|---|---|---|---|---|
| 1★ 软 | DRIL | ~4 | 10 | +6 |
| 2★ 软 | DRIL | ~4 | 20 | +16 |

3★ 软目标 = 18~52 门无星火炮的积分收益，是补基金的首选。

### 2.4 紧急移动换算（2026-08-18 修订：不再是地板重置）

- 紧急移动价值 = 一段**免费装填期**（暂停无时限，我方落地才解冻；实测一次 ~278 游戏秒自然解冻、期间我方未开炮）→ 按此样本折 **1 点 ≈ 4.3s**，与触发时机无关（不是 600−当前值）。
- 代价：取消手中两管任务 + 45 游戏秒冷却。派发不中断——暂停中照常装填（白嫖工时）。
- **对比击杀**：火炮 +30s 且 **+5 点**（净赚），时间效率 6s/点 且为正收入 → **能杀的时候，击杀永远比移动更划算**。移动只在"接下来一个暂停窗内杀不动"（无射程内火炮/断弹药/需要喘息转移）时才是正期望。
- 无星火炮总价值 ≈ 5 + 30s ≈ **8.3 点等价**（经济 + 生存，30s 按 4.5s/点 ≈ 6.7 点等价计）。
- 3★ 软目标 ≈ 30 点等价，**不含时间收益**——积分不能直接买 600s 地板（移动不重置），只能买暂停窗。
- DRIL 循环攒一次移动所需击杀数：满装 +0.5/杀 → 130 杀；最低装药 +1.75/杀 → 37 杀（移动仍是重储备，不是常规工具）。

### 2.5 集群经济 vs 单点

> **实战注（2026-08-18，用户观察 + 本局日志印证）**：游戏生成里**几乎不存在 2 门火炮同框**——最多"1 门火炮带 1 个步兵"。
> 本局 14 次入账全部是单门 +30s/+5，无一次双目标加账。集群经济因此是**理论上限**：HE/HCHE 的价值只剩
> "顺带清掉护送步兵"层面，不构成独立战术选项；多杀入账规则（按门 vs 按发）在本作实践中不可触发。

| 方案 | 成本 | 收入 | 周期 |
|---|---|---|---|
| 2×DRIL 打 2 门 | ~7 | +10 | 2 个发射周期 |
| 1×HE 打 2 门（贴脸） | ~11 | +10 | **1 个周期** |

- 积分上 DRIL 完胜（+3 vs ≈0）；时间上 HE 省一整轮装填的倒计时消耗（~25-35s）。
- 结论：**理论上有集群时时间吃紧优先 HE；实战无集群 → DRIL 单点恒为默认**，HE/HCHE 仅作回退链/顺带清步兵用。

## 3. 生存策略

### 3.0 激活条件与决策分层（新增规则如何并入现有规则）

**激活（两级，FDC 识别 = 无尽反炮兵模式识别，不用关卡号）**：

| 级 | 信号 | 含义 |
|---|---|---|
| 模式级 | 雷达扫到 **FDC 目标**（fire direction icon） | **无尽反炮兵模式**——剧情反炮兵关无 FDC、轻松模式无 FDC（均已确认），FDC 是此模式的独有指纹 |
| 状态级 | **倒计时开始走动**（第一发炮弹落地后） | 阶段机开始走：宽裕 → 吃紧 → 危急 |

无 FDC → 现有规则原样运行，一行不改（含剧情反炮兵关、轻松模式）。

**与现有决策的关系（分层，不是替换）**：

| 层 | 内容 | CBT 关处理 |
|---|---|---|
| 保留 | DRIL 单点软（现有已默认）、集群 HE≥2/HCHE≥4、装甲 AP、回退链、cost 排序、注册表、调度 | **原样** |
| 替换 | 优先级：现有 6 档 | 换 CBT 双轨表（§3.3）——同一排序管道，只换优先级数字 |
| 替换 | 装药：现有恒最低 | 换 CBT 双轨（§3.2）——同一装填管道，只换装药数 |
| 新增 | — | FDC 扣留 + 暂停组合拳（§3.4）——**模式级生效**（倒计时未启动的开局阶段也扣，否则开局连打 3 个 FDC 的教训重演） |
| 新增 | — | 基金线 90 点采购纪律（§3.6） |
| 新增 | — | 紧急移动自动触发（§3.5） |

**切换时机**：任务派发时按**当前阶段**定格（宽裕/吃紧/危急 → 优先级与装药一次定死），派发后不中途改——与手动/自动切换的原子性语义一致。

**范围声明**：以上全部规则仅用于**无尽反炮兵模式**。剧情反炮兵关（有倒计时但无 FDC）走现有规则，不做特化——与用户确认的范围一致。

### 3.1 三阶段总览

```
开局(倒计时未启动) → 宽裕期(>360s) → 吃紧期(<360s) → [危急(<240s) → 紧急移动买暂停窗] → 原值继续（无 600s 地板）
```

| 阶段 | 目标 | 手段 |
|---|---|---|
| 开局 | 建立 DRIL 循环 + 攒基金 | 打最近的火炮/3★，首轮落地启动倒计时 |
| 宽裕 | 积分滚雪球 | 星标优先 + 火炮循环，最低装药 |
| 吃紧 | 保时间 | 火炮最优先 + 满装抢节奏，集群 HE |
| 危急 | 买免费装填期 | 自动紧急移动（65点 → 冻结、我方落地解冻，**不重置**，§2.4） |

### 3.2 双轨装药

| 倒计时 | 装药 | 理由 |
|---|---|---|
| ≥360s（宽裕） | 最低装药 | 高利润攒存款（+0.75~1.75/杀，攒移动弹药 65 点） |
| <360s（吃紧，Urgent） | 满装 6 包 | 仰角行程缩短 → 击杀间隔 −5~27s，薄利(+0.5)换节奏；实测节省 <15s/发则弃用 |

### 3.3 双轨优先级

> 与 CbtMonitor 同步：吃紧阈值 Urgent=360s，危急阈值 Critical=240s（旧文档 300/180 已废）。

| 优先级 | 宽裕期（≥360s） | 吃紧期（<360s） |
|---|---|---|
| 最高 | 3★ 任何目标（印钞） | 火炮（+30s 硬通货） |
| 高 | 火炮（循环+时间） | 3★（补基金） |
| 中 | 1-2★ | 1-2★ |
| 中 | 高价值/弹药库（有收入，数值待实测） | 高价值/弹药库 |
| 保底 | 普通目标 | 普通目标 |

### 3.4 FDC 时机（暂停组合拳）

**非危急绝不打**：开局倒计时未启动时打 = 纯浪费；宽裕期打 = 浪费暂停储备。

**暂停语义（由"FDC 先落地就完蛋"反推）**：暂停在**下一次炮弹落地时解除**。因此 FDC 先落地 → 暂停刚启动就被下一发落地解掉 → 白费一个 FDC。

**正确顺序：火炮先落地，FDC 后落地**：

```
倒计时吃紧 → 双管装填：一管打火炮、另一管打 FDC（火炮弹先出膛/更近 → 先落地）
→ 火炮弹先落地 → +30s 入账
→ FDC 弹随后落地 → 倒计时暂停
→ 暂停窗口 = 从 FDC 落地到下一次炮弹落地：覆盖双管下一轮装填 + 下一发飞行（~70~150s 时钟不烧）
→ 下一发落地 → 暂停解除，回到正常循环
```

- 暂停**没有自己的时限**（2026-08-18 用户钉死）：不开炮就挂在冻结值几小时不变，我方落地才解冻。所以暂停 = **免费装填期**：两管都装好、双管就绪后先后开炮对齐同时落地（与开局一套逻辑）——那一次落地 = 解冻 + 照常 +30/门入账。
- 3 个 FDC = 3 次暂停：FDC 击杀落地 = 结此暂停+起新暂停（续暂停链，2026-08-16 用户确认），链上有 FDC 可一直续。
- 节奏：危急时先给火炮上膛（先落地）、再给 FDC 上膛（后落地）——两管装填顺序即落地顺序。
- 最坏情况（无 FDC 可用）：回到纯火炮循环 + 紧急移动兜底。

### 3.5 紧急移动（暂停窗，2026-08-18 修订：不是地板重置）

- 触发（与 CbtMonitor 同步）：倒计时 < 240s（Critical）且积分 ≥ 基金线 90。
- 价值 = 倒计时冻结一段免费装填期（解冻事件驱动；实测一次 ~278 游戏秒自然解冻，我方未开炮），与触发时机无关；代价 = 65 点 + 取消手中任务。
- **定位变化**：移动不再"救低值"（救不回来），而是"在杀不动的窗口挡住时钟燃烧"。能杀时优先杀（+30s 且 +5 点，优于移动的 4.5s/点 且为正收入，见 §5-13）。
- **应急基金纪律：积分常备 ≥ 90 点**（65 移动 + 25 重启资金）。移动后剩 25 点 ≈ 2~3 发 DRIL + 2 组药，足够重新点燃循环（每杀 +5 自滚动）。
- 跌破基金线时停止一切高价采购（AP/HCHE/装药囤积），只用 DRIL 维持循环。
